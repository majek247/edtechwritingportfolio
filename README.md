# GrowUp – HRtech Writing Portfolio

Vite + React + TypeScript + Tailwind + React Router. Homepage plus 3 full article pages.

```bash
npm install
npm run dev
```

- Edit articles in `src/data/articles.ts`
- Edit contact link / brand in `src/data/site.ts`
- Illustrations are inline SVG in `src/components/Art.tsx` (no external images)
